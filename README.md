# Allysa Joyce Dollano-Togonan — Portfolio

Personal portfolio website built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Files

- `index.html` — main portfolio page
- `styles.css` — responsive styling
- `script.js` — mobile navigation
- `assets/profile.jpg` — profile photo cropped from the supplied CV

## Before publishing

Replace the placeholder `#` links for LinkedIn and GitHub in `index.html`.

Replace the four sample project cards with real projects, screenshots, links, and measurable results where available.

## GitHub Pages

For a user site, create a public repository named:

`YOUR-GITHUB-USERNAME.github.io`

Upload the files in this folder to the repository root, then enable GitHub Pages from:

Settings → Pages → Build and deployment → Source → Deploy from a branch → `main` → `/ (root)`.
